# Macro Calculator

A simple, clean food energy calculator. Enter protein, fat, and carbs to instantly calculate calories using the Atwater factors (4-9-4 kcal/g).

## Features

- **Instant calculation** — real-time calorie computation as you type
- **Common food presets** — 40+ fitness foods with realistic portion sizes
- **Custom foods** — save your own foods for quick reuse
- **BMR tracking** — set your body metrics, see intake vs. daily needs
- **kJ ↔ kcal converter** — built-in unit conversion
- **Bilingual** — Chinese / English toggle
- **Privacy-first** — all data stored locally in your browser, no server, no tracking

## Usage

Open `index.html` in any browser. No installation needed.

Or visit the live version: https://faye-ovo.github.io/macro-calculator/
